# Current portfolio

The portfolio uses a monochrome device composition inspired by Foldfolio, with original SVG technical illustrations instead of portraits. Navigation contains Work, About and Contact. The UI is English-only.

All 18 projects remain accessible. The list is an editorial ranking of implemented engineering scope (service integration, concurrency/recovery, independent evaluation), not a score or externally validated difficulty measure. Breakroom, Signalworks and Pair Bench lead; unreplicated research archives appear last. Every case preserves source links, verification and limitations separately from its plain-language introduction.

Verification: `npm run type-check`, `npm run lint`, `npm run build`; real Chrome desktop/390px, filters and all 18 case routes. No model inference occurs on the portfolio itself. Earlier phase2 documentation describes the previous interface and historical model experiments.

Nine preview images are actual browser captures of the working project interfaces (public/previews), not fabricated mockups. They load lazily and use unoptimized local image files so no image-processing service is required. Original technical SVGs remain for the hero and source-only projects. Case descriptions now match football training/queries, travel report/reading examples, actual Steam counts, recorded coding attempts and their separate local backends.

The main tasks need no downloaded AI model. Current and Neon train small models directly in the browser. Pair Bench and Answer Key can replay actual prior model outputs and run independent checks. Free cloud-generation adapters are deployed but remain disabled without an explicitly confirmed free provider connection. No API keys, paid plan, billing or fallback were configured. Free provider quotas are limited; unlimited free cloud LLM training or serving is not claimed.
